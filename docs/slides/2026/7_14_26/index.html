Distill1

HTML output format for R Markdown documents – optimized for scientific and technical web–based communication

Distill.pub emphasized moving beyond static PDFs. It offered prizes for outstanding explanatory work and aimed to legitimize non-traditional research artifacts (e.g., interactive articles).


The name and core design come from the Distill web framework, originally created for Distill.pub, an online scientific journal focused on machine learning (launched around 2016–2017).
