#151:

…citing packages with pakret

  • Overview
  • pkrt()
  • pkrt_list()
  • pkrt_set()

Small, focused package with 3
“on–the–fly” functions:

  • pkrt() – cite R or R package
  • pkrt_list() – cite collection of R packages
  • pkrt_set() – configure settings

Alternative citation options:

  • knitr::write_bib()
  • papaja::r_refs()
  • grateful::cite_packages()
```
library(plotly)
library(pakret)

fig <- plot_ly(data = iris, x = ~Sepal.Length, y = ~Petal.Length, color = ~Species, colors = "Set1")

fig

```
